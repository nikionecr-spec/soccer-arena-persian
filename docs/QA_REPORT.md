## ۲. آزمون مرورگر واقعی (headless Chromium با ماوس/کلیک واقعی)

- ثبت‌نام کاربر با نام فارسی از UI → ورود به صفحه اصلی با ارقام فارسی ✔
- تمرین آفلاین: درگ ماوس روی مهره → گل واقعی (۱:۰) → ربات و شوت خودکار تایمر → صفحه نتیجه ✔
- **مسابقه آنلاین کامل**: مرورگر + حریف e2e (`server/test/browser_opponent.js`) → نتیجه نهایی ۳:۲؛ صفحه نتیجه فارسی: «شکست / ۲:۳ / −۱۶ امتیاز / +۳۵ سکه / مسابقه رنکد» — محاسبات سکه صحیح (۱۵ باخت + ۲×۱۰ گل) ✔
- صفحات فروشگاه (۵ مهره + ۴ زمین)، رده‌بندی، تاریخچه، دوستان ✔
- بدون خطای جاوااسکریپت پس از اصلاحات ✔

## ۳. باگ‌های یافت‌شده و رفع‌شده در طول QA

1. سرور: سرعت پرتاب پس از پایان شبیه‌سازی خوانده می‌شد (vx,vy=۰) → ثبت فوری پس از shoot
2. سرور: بسته‌شدن اتصال قدیمی در جایگزینی نشست، اتاق و مسابقه را خراب می‌کرد → گارد اتصال فعلی
3. سرور: کوانتیزه‌سازی وضعیت سرور به فرمت شبکه برای پاریتی کامل
4. کلاینت: حلقه انیمیشن آنلاین `PHYS.step` را صدا نمی‌زد → رفع؛ انیمیشن online اکنون کامل
5. کلاینت: crash شعاع منفی canvas هنگام ابعاد صفر → مقاوم‌سازی resize/clamp/try-catch
